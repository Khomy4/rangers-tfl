# TFL Rangers — Telegram Mini App v1.0

Мини-приложение для команды Rangers в Тульской Футбольной Лиге.

## Возможности

- Автоматическая регистрация игрока при первом входе
- Список матчей с дедлайном RSVP
- Подтверждение участия (до дедлайна — самостоятельно, после — только капитан)
- Капитан видит полный список RSVP (✅/❌/❓) по каждому игроку
- Голосование за MVP и лучшего защитника (только для сыгравших)
- Капитан закрывает голосование
- Детальный экран матча: счёт, статистика, RSVP, голосование
- Капитан вносит и правит голы / ассисты / вратарские очки
- Автоматический командный банк (дисциплина + результат)
- Накопительный личный фонд (600 ₽ за сыгранный матч)
- Управление сезонами (статистика не смешивается)
- Рейтинг игроков

## Локальный запуск

```bash
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows:
.venv\Scripts\activate

pip install -r requirements.txt
cp .env.example .env
# Отредактировать .env (оставить DEV_MODE=true для теста)
uvicorn app:app --reload --port 8000
```

Открыть http://127.0.0.1:8000

## Деплой на Render.com

1. Загрузить код в GitHub-репозиторий (приватный).
2. Создать **Web Service** на render.com → подключить репозиторий.
3. Настройки:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app:app --host 0.0.0.0 --port $PORT`
4. В разделе **Environment Variables** добавить:
   - `BOT_TOKEN` = (токен от @BotFather)
   - `CAPTAIN_TELEGRAM_ID` = (Telegram ID капитана)
   - `DEV_MODE` = `false`
5. После деплоя Render выдаст URL вида `https://rangers-tfl.onrender.com`.
6. В @BotFather → выбрать бота → **Bot Settings → Menu Button → Configure Menu Button** → вставить URL.

## Подключение к Telegram

1. Создать бота через @BotFather (или использовать существующего).
2. Разместить приложение на HTTPS (Render.com даёт HTTPS автоматически).
3. В `.env` указать `BOT_TOKEN` и `CAPTAIN_TELEGRAM_ID`.
4. В BotFather указать Web App URL.
5. Установить `DEV_MODE=false`.

> ⚠️ **Никогда не коммитить `.env` в Git!**  
> Файл `.env` уже добавлен в `.gitignore`.
